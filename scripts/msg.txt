fix: stop re-labelling the status dropdown options

The status select is the one place where an option's text is also the value the
app persists. Re-labelling "Applied" as "Submitted" there (while intent badges
and exports already carried the friendlier wording via lifecycleLabel) made the
select fall back to the first option, so a record at "Applied" displayed as
"Saved" and the legacy-migration e2e test failed in-file. The option text is the
stored status again; nothing invents eligibility, achievement or outcome either way.

Also removes a stray test seed-clearing line that emptied localStorage before the
migration assertions, and drops the now-redundant stageLabel helper.

Verified: typecheck clean; 144/144 unit tests pass; production build succeeds;
full Playwright suite 53/53 (previously 52/53 with the legacy-migration failure).
